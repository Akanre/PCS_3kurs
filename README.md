Виджеты которые использовались:

Использовавлись виджеты StatelessWidget, такие как:

Textfont

Scaffold

AppBar
  
Body

Container

SizedBox

Row

Column

ElevatedButton

Icon

Стили и цвета:

Для text стиль менялся с помощью параметра style. Использовалось 2 параметра: fontSize и fontWeight.

Для container стиль менялся с помощью width и height. Цвет менялся через параметр color.

Для иконок цвет менялся через параметр color, но 2 способами:
1) Color.fromARGB(255, 159, 80, 52)
2) Colors.blue

В ходе работы трудностей не возникло.
