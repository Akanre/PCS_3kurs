Для выполнения данного задания, были созданы 3 экрана(Welcome, Main screen, Add item screen)
<img width="1530" height="936" alt="image" src="https://github.com/user-attachments/assets/69ebe7b0-78a6-4650-8793-8f4b30a03cae" />

1) Экран приветствия(Welcome)
   Для данного экрана использовался элемент Ellipse для обозначения места будущего логотипа и Rectangle для создания кнопки("Начать"). Для дизайна кнопки использовалось скругление краев(16) + цвет #359CFD. При нажатии на кнопку "Начать", пользователь перемещается на Главный экран(Main screen).
2) Главный экран(Main screen)
   На главном экране видна главная панель с названием приложения в Rectangle в самом верху экрана. Ниже, в Rectangle, создан список элементов. Есть возможность добавить новую задачу, при помощи кнопки "Добавить задачу". Кнопка выполнена с помощью Rectangle со скруглением краев(16) и изменения цвета на #359CFD. При нажатии на кнопку "Добавить задачу", пользователь перемещается на экран добавления элемента.
3) Экран добавления элемента(Add item screen)
   На экране добавления задач, есть поле для ввода текста. Поле ввода создано при помощи Rectangle. Ниже имеется кнопка "Сохранить". Кнопка сделана с помощью Rectangle. Для кнопки использовалось скругление краев(16) и изменение цвета на #359CFD. В самом низу экрана располагается кнопка "Назад". Данная кнопка создана при помощи элемента Rectangle. Для дизайна кнопки использовалось скругление краев(16) + цвет #359CFD. После ввода текста и нажатии кнопки "Сохранить", пользователь перемещается на главный экран, а новая задача добавлятся в список элементов. При нажатии на кнопку "Назад", пользователя вернет на главный экран.
